## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/bharathchandralakdaram-boop/portfolio.git
   cd portfolio
   ```

2. **Add your profile photo**
   - Place your photo at `images/profile.jpeg`
   - In `index.html`, replace the `<div class="profile-fallback">` with:
     ```html
     <img src="images/profile.jpeg" alt="Bharath Chandra" class="profile-photo">
     ```
   - Do the same in `about.html` for the About section image.

3. **Open in browser**
   - Simply open `index.html` in any modern browser — no build step needed.

---

## 🌍 Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Set source to **Deploy from branch → main → / (root)**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## ✨ Features

- 🎨 Dark navy + gold design system with CSS variables
- 📱 Fully responsive (mobile, tablet, desktop)
- ✨ Scroll-reveal animations with IntersectionObserver
- 📊 Animated skill progress bars
- 🎭 Animated morphing profile image with orbit rings
- 📬 Contact form with submit feedback
- 🏆 Certificate cards with Bootstrap modal
- ♿ Semantic HTML with `aria` attributes
